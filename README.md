## About

**ToucanOS** is a small and lightweight Linux-based operating system designed primarily for **embedded systems and low-level environments**.

The project focuses on keeping the system as simple and lightweight as possible. ToucanOS boots directly into RAM using `initramfs` and starts a minimal shell.

There is no GUI, no `systemd`, and no unnecessary components.

The main goal of ToucanOS is to provide a small Linux environment that can be adapted for embedded hardware and experimental systems.

> **Status:** Early Beta

---

## Features

* Minimal Linux userspace
* Designed for embedded systems
* `initramfs`-based root filesystem
* Runs from RAM
* No GUI
* No `systemd`
* Built from source
* x86_64 support
* QEMU support

---

## Requirements

To build ToucanOS, you need a Linux system with:

```text
bash
cpio
gzip
xorriso
grub-pc-bin
qemu-system-x86
```

On Debian/Ubuntu:

```bash
sudo apt install bash cpio gzip xorriso grub-pc-bin qemu-system-x86
```

You will also need the Linux kernel and the other build tools used by `build.sh`.

---

## Build

Clone the repository:

```bash
git clone https://github.com/<username>/ToucanOS.git
cd ToucanOS
```

Make the build script executable:

```bash
chmod +x build.sh
```

Build the ISO:

```bash
./build.sh
```

After the build finishes, the bootable ISO will be generated by the script.

---

## Run with QEMU

You can test ToucanOS without real hardware:

```bash
qemu-system-x86_64 -cdrom ToucanOS.iso
```

For a headless test:

```bash
qemu-system-x86_64 -cdrom ToucanOS.iso -nographic
```

## ISO Releases

Ready-to-use ISO images will be available on the project's **GitHub Releases** page.

If you don't want to build ToucanOS yourself, simply download the latest ISO from Releases.

Alternatively, you can build the system yourself using:

```bash
./build.sh
```
